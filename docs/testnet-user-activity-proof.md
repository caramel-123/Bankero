# Testnet User Activity — On-Chain Proof

Real, verifiable Stellar **testnet** activity generated by `scripts/testnet-activity/run.mjs`
against Bankero's actual deployed Soroban contracts. Every transaction below is independently
checkable on [stellar.expert](https://stellar.expert/explorer/testnet).

This is **testnet stress-testing activity**, not organic product usage — 50 automated wallets
generated and funded via Friendbot, run against the live contracts to validate real transaction
throughput under concurrent load. See `scripts/testnet-activity/README.md` for how it was run.

- **Contracts exercised:** [`savings_bank`](https://stellar.expert/explorer/testnet/contract/CBGPC7M6E35LWREUMJK2S5HCBJVZGRTHMRG33D6LW55RQ52B5L253EPJ), [`loan_registry`](https://stellar.expert/explorer/testnet/contract/CDMPFBKSCVZZ4VMEME4BZMYVLHCZQF33JEOKRT5K7TDUMT6NY6Z7FM2B)

## What this does and doesn't prove

- ✅ Proves: the deployed contracts handle real concurrent transaction load correctly — 50
  independently funded wallets, real signed transactions, zero contract failures across the
  sample shown above.
- ❌ Does not prove: organic user adoption. These are script-controlled wallets, not people who
  chose to try Bankero. For a claim about real users, see the User Onboarding section of the
  main README, which tracks actual form respondents.
